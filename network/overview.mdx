<Info>
  The DATA Network is being upgraded to run as a protocol natively on Sui. Once
  the upgrade is complete, this independent layer 1 chain will be retired. It
  keeps running until then, and these docs remain for node operators,
  validators, and existing integrations. See [DATA on Sui](/data-on-sui).
</Info>

The DATA Network is a Layer 1 blockchain for data provenance, with full EVM compatibility and an optimized execution layer.

  Do not use `RANDAO` for pseudo-randomness, instead use onchain VRF (Pyth or
  Gelato). Currently, `RANDAO` value is set as the parent block hash and thus is
  not random for X-1 block.
</Warning>
