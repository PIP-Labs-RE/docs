## Trace

[Trace](/trace/overview) is the data-provenance and audit layer. Providers integrate over a simple REST API. See the [Trace Integration Guide](/trace/integration).

## Confidential Data Rails (CDR)

CDR is the primary way to encrypt, store, and gate access to confidential data on the DATA Foundation.

- [CDR SDK Guide](/developers/cdr-sdk/overview) - a step-by-step walkthrough of the `@piplabs/cdr-sdk`, from setup to encrypting data and configuring access control **_(includes working code)_**
- [CDR SDK Reference](/sdk-reference/cdr/overview) - detailed **explanations and examples** for every function in the CDR SDK

<Warning>
  Do not use `RANDAO` for pseudo-randomness, instead use onchain VRF (Pyth or
  Gelato). Currently, `RANDAO` value is set as the parent block hash and thus is
  not random for X-1 block.
</Warning>

## API

Use the [Trace Integration Guide](/trace/integration) for data provenance, the [Blockscout API](/api-reference/blockscout-api) for network statistics, or the [Consensus Client API](/api-reference/consensus-client/introduction) for node queries.
