<AccordionGroup>

<Accordion title="What's the token?">
  $DATA. It remains the token of the DATA protocol on Sui, carried over
  one-to-one, with holder economics and governance rights at least equivalent
  to today's.
</Accordion>

<Accordion title="What's happening to the DATA Network?">
  The DATA Network will be upgraded to run as a protocol natively on Sui, and
  its independent layer 1 chain will be retired. A detailed timeline and
  transition plan will be published before the upgrade. See [DATA on
  Sui](/data-on-sui).
</Accordion>

<Accordion title="Do I need to do anything right now?">
  No. The existing DATA Network keeps running until the upgrade is complete.
  Its docs are still available under the [Legacy Network](/network/overview)
  tab.
</Accordion>

<Accordion title="Where is data stored?">
  [Walrus](https://walrus.xyz) becomes the default storage layer for DATA
  Foundation apps.
</Accordion>

<Accordion title="How do I integrate with Trace?">
  Trace is a REST API keyed by an API key and provider scope, no SDK required.
  [Contact our team](https://discord.gg/databuilders) to get onboarded, then
  follow the [Trace Integration Guide](/trace/integration).
</Accordion>

  View the [disclaimers](/foundation/disclaimer).
</Accordion>

</AccordionGroup>
