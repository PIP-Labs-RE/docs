<Accordion title="토큰은 무엇인가요?">
  $DATA입니다. Sui 위의 DATA 프로토콜 토큰으로 유지되며, 1:1로 이전되고,
  보유자 경제 및 거버넌스 권리는 최소한 현재와 동등하게 유지됩니다.
</Accordion>

<Accordion title="DATA Network는 어떻게 되나요?">
  DATA Network는 Sui에서 네이티브로 실행되는 프로토콜로 업그레이드되며, 독립적인
  레이어 1 체인은 종료됩니다. 자세한 일정과 전환 계획은 업그레이드 전에 공개될
  예정입니다. [Sui 위의 DATA](/ko/data-on-sui)를 참고하세요.
</Accordion>

<Accordion title="지금 해야 할 일이 있나요?">
  없습니다. 기존 DATA Network는 업그레이드가 완료될 때까지 계속 운영됩니다.
  관련 문서는 [레거시 네트워크](/ko/network/overview) 탭에서 계속 확인할 수
  있습니다.
</Accordion>

<Accordion title="데이터는 어디에 저장되나요?">
  [Walrus](https://walrus.xyz)가 DATA Foundation 앱의 기본 스토리지 레이어가
  됩니다.
</Accordion>

<Accordion title="Trace와 어떻게 통합하나요?">
  Trace는 API 키와 provider 범위로 인증하는 REST API이며, SDK가 필요하지
  않습니다. [팀에 문의](https://discord.gg/databuilders)하여 온보딩한 다음
  [Trace 통합 가이드](/ko/trace/integration)를 따르세요.
</Accordion>

<Accordion title="면책 조항은 무엇인가요?">
  [면책 조항](/ko/foundation/disclaimer)을 확인하세요.
</Accordion>

</AccordionGroup>
