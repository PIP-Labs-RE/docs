## Prove Data Provenance With Trace

If you're a data provider, [Trace](/trace/overview) gives you verifiable, provider-normalized provenance for the data you handle (content hashes, contributor consent, and KYC signals, with public audit views) through a simple REST integration.

</CardGroup>

## Build with CDR

[Confidential Data Rails (CDR)](/cdr/overview) lets you encrypt, store, and control access to confidential data on the DATA Foundation using `@piplabs/cdr-sdk`.

<CardGroup cols={2}>
  <Card title="CDR SDK Setup" icon="screwdriver-wrench" href="/developers/cdr-sdk/setup">
    Install the SDK and initialize a client on Aeneid testnet.
  </Card>
  <Card title="Encrypt & Decrypt" icon="lock" href="/developers/cdr-sdk/encrypt-and-decrypt">
    Encrypt a secret or file and recover it through threshold decryption.
  </Card>
</CardGroup>

See the [CDR SDK Reference](/sdk-reference/cdr/overview) for method parameters and examples.
