## Trace

[Trace](/ko/trace/overview)는 데이터 출처 및 감사 레이어입니다. 프로바이더는 간단한 REST API를 통해 통합합니다. [Trace 통합 가이드](/ko/trace/integration)를 참조하세요.

## Confidential Data Rails (CDR)

CDR은 DATA Foundation에서 기밀 데이터를 암호화하고, 저장하고, 접근을 게이팅하는 주요 방법입니다.

- [CDR SDK 가이드](/ko/developers/cdr-sdk/overview) - 설정부터 데이터 암호화, 접근 제어 구성까지 `@piplabs/cdr-sdk`의 단계별 가이드 **_(작동하는 코드 포함)_**
- [CDR SDK 참조](/ko/sdk-reference/cdr/overview) - CDR SDK의 모든 함수에 대한 자세한 **설명과 예제**

<Warning>
  의사 난수에 `RANDAO`를 사용하지 말고, 대신 온체인 VRF(Pyth 또는 Gelato)를
  사용하세요. 현재 `RANDAO` 값은 부모 블록 해시로 설정되어 있으므로 X-1
  블록에 대해 무작위가 아닙니다.
</Warning>

## API

데이터 출처에는 [Trace 통합 가이드](/ko/trace/integration)를, 네트워크 통계에는 [Blockscout API](/ko/api-reference/blockscout-api)를, 노드 쿼리에는 [Consensus Client API](/ko/api-reference/consensus-client/introduction)를 사용하세요.
